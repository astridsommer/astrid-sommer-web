# Astrid Sommer — sitio web

Proyecto independiente para astridsommer.com. Next.js + Sanity (CMS) + Vercel.

## Desarrollo local

```
npm install
npm run dev
```

Panel de administración de contenido (Noticias, Obras, Exposiciones, Reseñas, Bio): `/studio`

## Variables de entorno

Ver `.env.example`. `.env.local` no se sube al repositorio.
